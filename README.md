🔍 X Mind Reader

A Python Number Guessing Game by NOT YOUR LIV

Think you can read the computer's mind? 🎯

Guess the secret number between 1 and 100 using interactive Hot & Cold hints!

✨ Features

- 🎯 Random number generation
- 🔥 Hot & Cold hints
- 📈 Warmer and colder feedback
- 🔢 Attempts counter
- 🏆 Different victory messages
- 🔁 Replay option
- ⚠️ Input validation

🛠️ Built With

- Python 3
- Random module

🎮 How to Play

1. Start the game.
2. Guess a number between 1 and 100.
3. Follow the hints to get closer to the secret number.
4. Find the correct number to win!
5. Play again if you want another round.

▶️ How to Run

Make sure Python 3 is installed.

Run this command in your terminal:

python3 main.py
